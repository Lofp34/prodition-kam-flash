## Conseils photo

- cadrage horizontal ;
- élément principal net et bien éclairé ;
- éviter les visages et informations personnelles ;
- photographier de préférence le bateau réel du stage ;
- conserver la même photo pour la version annotée ;
- résolution conseillée : 1600 × 1000 px environ ;
- poids cible : moins de 500 Ko par image.
